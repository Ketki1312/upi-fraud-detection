     5→     5→## Environment Adaptation Note
     6→     6→The reference specification calls for FastAPI + PostgreSQL + React (Vite). This sandbox is locked to Next.js 16 + Prisma SQLite + a single user-visible `/` route. Pragmatic adaptation:
     7→     7→
     8→     8→- **Frontend**: Next.js 16 + TypeScript + Tailwind 4 + shadcn/ui, single page with tab navigation (covers all 13 required views).
     9→     9→- **ML/NLP/XAI/Drift**: Python FastAPI mini-service (`mini-services/ml-service/`, port 4000) using scikit-learn, XGBoost, SHAP, LIME. Trains real models from real data.
    10→    10→- **Database**: Prisma SQLite (replaces PostgreSQL). Same logical schema.
    11→    11→- **API bridge**: Next.js API routes (port 3000) proxy to the Python ML service via `XTransformPort=4000` and persist to Prisma SQLite.
    12→    12→- **Visualization**: Recharts + custom SVG (Plotly equivalent for React/SSR safety).

    96→    96→## API Contract (ML service ↔ Next.js bridge ↔ Frontend)
    97→    97→
    98→    98→All ML-service endpoints live at `http://localhost:4000` (proxied via `?XTransformPort=4000`). Same JSON shapes as the docx spec.
    99→    99→
   100→   100→- `GET /health` → `{status, models_loaded: {transaction: bool, nlp_en/hi/hinglish/combined: bool}}`
   101→   101→- `POST /api/v1/transactions/analyze` → body `{step, type, amount, oldbalanceOrg, newbalanceOrig, oldbalanceDest, newbalanceDest}` → `{prediction, probability, risk_score, risk_level, model_version, explanation:{contributions:[{feature, value, contribution, human_label}], baseline, method}}`
   102→   102→- `POST /api/v1/messages/analyze` → body `{text, language?}` → `{prediction, probability, risk_score, risk_level, model_version, language_detected, explanation:{tokens:[{token, weight}], method, top_positive, top_negative}}`
   103→   103→- `POST /api/v1/risk/analyze` → body `{transaction?, message?}` → `{unified_risk_score, risk_level, transaction_risk, message_risk, fusion_method, disclaimer}`
   104→   104→- `GET /api/v1/dashboard/summary` → `{total_predictions, fraud_count, scam_count, risk_distribution:{low, medium, high, critical}, language_distribution, model_metrics}`
   105→   105→- `GET /api/v1/dashboard/trends` → `{timestamps[], risk_trend[], fraud_rate_trend[]}`
   106→   106→- `GET /api/v1/drift/status` → `{features:[{feature, psi, status, threshold}], last_updated}`
   107→   107→- `GET /api/v1/drift/history` → `{events:[{id, feature, reference_period, current_period, psi, status, action_taken, created_at}]}`
   108→   108→- `GET /api/v1/models` → `{models:[{name, version, dataset_version, training_timestamp, active, metrics:{precision, recall, f1, roc_auc, pr_auc?}}]}`
   109→   109→- `POST /api/v1/models/retrain` → body `{model_name, drift_window?}` → `{candidate_version, old_metrics, new_metrics, promoted, comparison}`
   110→   110→
